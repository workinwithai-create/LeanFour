# LeanFour

Four-bar lean-in desk for bedroom producers and AI-music finishers.

Square 4-bar loops feel stuck. Session players lean the harmony (piano, nylon, upright) into the next chord on the last beat while the kit stays locked to the grid.

Live FluidR3 samples only (pinned to soundfont-for-samplers@0.0.3).

## Distinct from

- TensionFour (pedal hold)
- DriveFour (kick pushes)
- PulseFour (steady pulse)
- AccentFour / SparkFour / etc.

Free. Audio never leaves the tab.

## Acceptance

Engine follows WorkinWithAI rules 1–4. Exports are stubs in this MVP; full OfflineAudioContext folded-tail WAV and multi-track MIDI required before calling fully shippable.
